# Лабораторная работа 1 по дисциплине "Технологии Программирования"
## Вариант 1

Программа читает оценки из TXT и YAML, выводит средний балл каждого студента и считает отличников. Студент считается отличником, если у него по каждой дисциплине 90 баллов или больше.

`TextDataReader` и `YamlDataReader` реализуют интерфейс `DataReader` и возвращают данные в одном формате. `CalcRating` вычисляет средний балл, а `CalcExcellentStudents` проверяет оценки по отдельным дисциплинам.

## Запуск

Для запуска нужно выполнитьь команды из корня проекта в PowerShell.

```powershell
python -m pip install -r requirements.txt
python src/main.py -p data/data.yaml
```

## Тесты

```powershell
$env:PYTHONPATH = '.;src'
python -m pytest test
python -m pycodestyle src test
```

На примере `data/data.yaml` программа выводит `Количество студентов-отличников: 1`. Студенд Иванов набрал 90, 95 и 100 баллов и прошёл порог по всем дисциплинам. У Петрова средний балл выше 90, но по химии он набрал 89.

#### Подсчёт отличников — `test_CalcExcellentStudents.py`

1. **Три студента.** У `A` оценки 90 и 90, у `B` — 100, у `C` — 100 и 89. Ожидается `2`. Проверяет, что 90 входит в порог, а одна оценка 89 исключает студента из подсчёта.
2. **Одна оценка 89.** Ожидается `0`.
3. **Студент без оценок.** Ожидается `0`.
4. **Пустой словарь студентов.** Ожидается `0`.

#### Средний балл — `test_CalcRating.py`

5. `test_init_calc_rating` — проверяет, что конструктор `CalcRating` сохраняет переданный словарь оценок.
6. `test_calc` — проверяет средний балл на примере двух студентов. Ожидаются значения `85.3333` и `79.0` с допуском `0.001`.

#### Чтение TXT — `test_TextDataReader.py`

7. `test_read` — читает временный TXT-файл с двумя студентами и сравнивает результат с ожидаемым словарём ФИО, предметов и оценок.

#### Чтение YAML — `test_YamlDataReader.py`

8. `test_read_yaml` — читает корректный YAML с двумя студентами и проверяет ФИО, названия предметов на кириллице и оценки.
9. `test_read_empty_yaml` — для пустого файла ожидает пустой словарь `{}`.
10. `test_read_empty_yaml` — для файла со списком `[]` также ожидает `{}`.
11. `test_read_invalid_structure` — отклоняет словарь на верхнем уровне, где должен быть список студентов.
12. `test_read_invalid_structure` — отклоняет элемент списка, содержащий только строку с именем.
13. `test_read_invalid_structure` — отклоняет элемент списка, в котором записаны сразу два студента.
14. `test_read_invalid_structure` — отклоняет числовое имя студента `12`.
15. `test_read_invalid_structure` — отклоняет пустое имя студента.
16. `test_read_invalid_structure` — отклоняет повторную запись студента с тем же именем.
17. `test_read_invalid_structure` — отклоняет список оценок `[90]`, где должен быть словарь «предмет → балл».
18. `test_read_invalid_structure` — отклоняет запись студента с пустым словарём оценок.
19. `test_read_invalid_structure` — отклоняет числовое название предмета `1`.
20. `test_read_invalid_structure` — отклоняет логическое значение `true` в поле оценки.
21. `test_read_invalid_structure` — отклоняет строку `'90'` в поле оценки, где ожидается целое число.
22. `test_read_invalid_yaml` — передаёт YAML с незакрытой скобкой и проверяет, что возникает `yaml.YAMLError`. В случаях **11–21** ожидается `ValueError`, потому что YAML разбирается, но его данные не подходят программе.

#### Аргументы и вывод программы — `test_main.py`

23. `test_get_path_from_correct_arguments` — проверяет, что аргумент `-p /home/user/file.txt` даёт путь `/home/user/file.txt`.
24. `test_get_path_from_noncorrect_arguments` — проверяет, что передача пути без обязательного `-p` вызывает `SystemExit`.
25. `test_main_prints_results` с `.yaml` — проверяет, что для YAML программа печатает средние баллы `90.0` и `94.5` и выводит **1 отличника**.
26. `test_main_prints_results` с `.YML` — проверяет тот же результат для расширения `.YML` в верхнем регистре.
27. `test_main_prints_results` с `.txt` — проверяет тот же результат для текстового файла и подтверждает, что добавление YAML сохранило поддержку TXT.
